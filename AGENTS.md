# Agent Rules

- Никогда не показывать на клиентском UI названия сторонних сайтов, домены или бренды внешних источников.
- Для всех пользовательских текстов в интерфейсе использовать нейтральные формулировки: `источник`, `каталог`, `внешний плеер`, `поток`.
- Если внешний идентификатор нужен пользователю, показывать его как `ID источника` без указания домена или бренда.
